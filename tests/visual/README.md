# Pruebas visuales de la Etapa A

Defina `E2E_TEST_EMAIL` y `E2E_TEST_PASSWORD` para un usuario de prueba activo. Las capturas cubren el shell autenticado a 1440, 900, 680 y 380 px. No se versionan credenciales, datos de demostración ni capturas aprobadas hasta disponer de un entorno Supabase de prueba determinista.

Ejecute `npx playwright install chromium` una vez y después `npm run test:visual`.
